# Celestial texture attribution

The locally stored textures in this directory were resized and converted to WebP for Aurora.

- `earth-blue-marble.webp` — NASA/Goddard Space Flight Center Scientific Visualization Studio, “Blue Marble — A Seamless Image Mosaic of the Earth”, asset `bluemarble-2048.png`, https://svs.gsfc.nasa.gov/2915
- `moon-lroc.webp` — NASA/Goddard Space Flight Center Scientific Visualization Studio, “CGI Moon Kit”, LRO color map asset `lroc_color_2k.jpg`, https://svs.gsfc.nasa.gov/4720

NASA SVS states that its content is public domain unless otherwise noted: https://svs.gsfc.nasa.gov/help/. Use remains subject to NASA's media usage guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/.
